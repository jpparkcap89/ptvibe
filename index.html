이 연수 사이트에서는 이렇게 연결합니다

  1. GitHub 안내 페이지에서 연수 내용을 확인합니다.
  2. 신청하기를 누르면 GAS 신청 페이지가 새 탭으로 열립니다.
  3. GAS 페이지의 google.script.run이 백엔드를 호출합니다.
  4. 백엔드에서 검사한 신청 정보가 구글 시트에 저장됩니다.

공개 설정만 안내 페이지에 전달합니다. 신청자 명단과 연락처는 공개 조회 기능에 포함하지 않습니다.

준비물과 계정

  1. 개인 노트북과 충전기를 준비합니다.
  2. 구글 계정과 GitHub 계정에 로그인할 수 있는지 확인합니다.
  3. 사용할 AI 서비스에 로그인합니다.
  4. Chrome 또는 Edge 등 브라우저를 준비합니다.

실습 안내

  1. 실습에는 가상의 학생·교직원 자료를 사용합니다.
  2. 공개 저장소에는 연락처와 비밀번호를 올리지 않습니다.
  3. 구글 시트 공유와 웹앱 실행 권한은 따로 확인합니다.
  4. 완료 메시지만 믿지 않고 실제 저장 결과도 확인합니다.
